A code editor widget for Gio, in Go.

Syntax highlighting, completions from any language server and side-by-side diffs for Go desktop apps, drawn by Gio in your own process, so the app ships one UI stack.

Attach a language server to the Editor.

lsp.Attach sends every edit to the server and fills the Editor's hooks from its answers. lsp/servers knows 428 servers and how to install 252 of them. Tested with gopls.

[ listing 1 ] cmd/examples/lsp, abridged

Quick start.

// go get github.com/lichdotdev/godemirror
editor, err := godemirror.NewEditor("monospace", unit.Sp(13))
err = editor.SetState(godemirror.EditorStateConfig{Filename: path, Doc: text})

srv := servers.Lookup(path)[0]
client, err := lsp.Start(ctx, lsp.Config{Command: srv.Command, RootDir: root})
doc, err := lsp.Attach(client, editor, lsp.FileURI(path), lsp.Options{
	LanguageID: servers.LanguageID(servers.FileType(path)),
	Invalidate: window.Invalidate,
})
editor.Layout(gtx) // in the frame loop

The library is pure Go; the app around it is an ordinary Gio app. Tested on Linux; macOS and Windows build but CI does not run them yet. Limits: docs/ceilings.md.
